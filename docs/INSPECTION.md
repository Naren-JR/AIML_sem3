# Initial architecture and data audit

The starting repository contained four Python scripts, five Australian-session telemetry CSVs, two PDF research documents, 21 section JSON files, a section archive, two image archives and an image event map. No existing model, backend, frontend source, package manifest, tests, handoff, screenshot or frontend.zip was present.

The fetcher exports fifteen numeric channels (time, rpm, speed, gear, throttle, brake, distance, rel_distance, DistanceToDriverAhead, acc_x/y/z, x/y/z). DriverAhead is not exported. The race CSV has 37,569 samples spanning 0–4990.011 s, no missing source cells, chronological session time, duplicate boundary times, and lap-local distance resets. Other sessions are intentionally excluded. Lap numbering must be inferred because the fetcher discarded original IDs. See generated results/source_audit.json for source hashes, per-file schemas/ranges and archive inventories.

The valid existing preprocess.py preserves source order and emits diagnostic flags; its acceleration is explicitly diagnostic. The new adapter reuses that design rather than altering source values or running all sessions through an ERS model. A separate adapter is necessary to isolate GP Race, retain original cell strings, infer lap boundaries and distinguish calculated versus estimated values. The existing scripts remain independently runnable with NumPy/Pandas installed. The missing circuitMap.json prevents running the existing track processor successfully on these inputs; the implementation does not fabricate that mapping.

Final architecture: backend/data.py (normalization/QC/selection), backend/model.py (continuous physical scenarios), backend/optimizer.py (gradient allocation), backend/api.py (FastAPI, cached state and background experiments), frontend/src (React/TypeScript, Router, Zod, Plotly and SVG). CSS is authored directly to keep the workstation layout compact. No JavaScript energy physics exists. Backend tests exercise actual race data; frontend tests use explicitly synthetic fixtures for selection/error edge cases. scripts/reproduce.py exports real-data experiments.
